# SocraticAI Tutor 🎓🤖

An AI-powered interactive learning platform designed to make learning easier, more engaging, and personalized for students.

## 📚 Subjects Available

* Physics
* Mathematics
* Chemistry
* Biology
* Computer Science
* Programming
* English
* History

## ✨ Features

* 🤖 AI Tutor for answering student questions
* 📖 Detailed explanations for better understanding
* 🧠 AI-powered quizzes
* 💡 Explanations for incorrect answers
* 📊 Progress tracking
* 📚 Subject and topic-based learning
* 🎯 Student-friendly interactive interface

## 🚀 How It Works

1. Choose a subject.
2. Select a topic or ask your own question.
3. Get a detailed explanation from the AI Tutor.
4. Test your knowledge with AI-generated quizzes.
5. Review incorrect answers and understand the explanations.
6. Track your learning progress.

## 🛠️ Technologies Used

* Google AI Studio
* HTML
* CSS
* JavaScript
* Generative AI

## 🎯 Purpose

The purpose of SocraticAI Tutor is to provide students with an interactive and accessible AI-powered learning experience where they can explore different subjects, ask questions, test their knowledge, and improve through personalized explanations.
